## FAQ

<details>
<summary><strong>Where do these come from?</strong></summary>

Understudy crawls the public job boards of about 20,000 companies — Greenhouse, Lever, Ashby, Workable,
SmartRecruiters, Recruitee, Workday, Oracle, iCIMS and Eightfold, plus Amazon's and Microsoft's own sites — on a
rolling schedule, with the boards that post most often re-checked every few minutes. These tables are a filtered
view of that crawl: open postings, published in the last 7 days, whose title says the role is an internship or co-op.

Because it reads the employer's own board, every link here is the real application page. There is no
intermediate posting that can go stale.
</details>

<details>
<summary><strong>How is a role classified?</strong></summary>

By title, with the rules in [`src/lib/lists/roles.ts`](https://github.com/Keugene11/understudy) in the
Understudy repo. Categories are matched in priority order, so a "Machine Learning Software Engineer" is filed
under Data/AI rather than Software Engineering. Non-software engineering disciplines (mechanical,
manufacturing, civil, industrial, chemical) are excluded, as are part-time, contract and student-worker
postings.

Classification by title is imperfect by nature. If something is in the wrong section, open an issue.
</details>

<details>
<summary><strong>Can I use this data?</strong></summary>

Yes. [`.github/scripts/listings.json`](./.github/scripts/listings.json) is the machine-readable version, and
it uses the same field names as the SimplifyJobs lists — so tooling written for those repos reads this one
without changes.
</details>

<details>
<summary><strong>Does applying through here cost anything?</strong></summary>

No. Every **Apply** link goes directly to the employer. **⚡ Auto-apply** is the optional other way: it opens
Understudy, which fills in and submits that application for you instead of you doing it by hand.
</details>
